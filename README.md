# CK3 Simple UI (1.21 Trade & City)

Crusader Kings III **1.21 "Florin" (*Silk & Silver*)** 업데이트에서 개편된 **무역(시장·교역로)** 및 **도시/구역(District) 건설** UI를 더 심플하고 한눈에 알아보기 쉽게 개선하는 모드입니다.

## 📁 프로젝트 구조

- `.agents/`: 에이전트 룰(`rules/`), 하네스 스킬(`skills/`), 도메인 히스토리(`history/`), 트러블슈팅 기록(`records/`)
- `docs/`: UI 기획안 및 바닐라 1.21 GUI 분석 문서
- `mod/`: CK3 모드 본체 (`descriptor.mod`, `gui/`, `common/scripted_guis/`, `localization/`)
